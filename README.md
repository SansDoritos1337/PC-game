# BYTEWORKS — PC & Serwerownia

Prywatny prototyp gry warsztatowej w Godot 4. Kupuj podzespoły inspirowane rzeczywistymi produktami, składaj komputery gamingowe i serwery, pilnuj zgodności części i realizuj zlecenia.

## Uruchomienie

1. Zainstaluj Godot 4.x.
2. Otwórz `project.godot` w Godot Project Managerze.
3. Naciśnij **F6** lub **F5**, aby uruchomić grę.

## Pętla rozgrywki

- Kupuj procesory, płyty główne, pamięć, karty graficzne, dyski, zasilacze i obudowy.
- Wybieraj zakupione części na stanowisku montażowym.
- Sprawdzaj zgodność gniazd procesora, formatów płyty i obudowy oraz mocy zasilacza.
- Zrealizuj zlecenie na komputer albo serwer i odbierz wypłatę.

Części są opisane nazwami rzeczywistych modeli i przybliżonymi parametrami. BYTEWORKS, interfejs i rozgrywka są autorskim prototypem; projekt nie używa cudzych logotypów ani materiałów graficznych.
